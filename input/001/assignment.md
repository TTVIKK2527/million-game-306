# JavaScripti kalkulaator

## Ülesande kirjeldus

Loo lihtne kalkulaator, mis võimaldab kasutajal teostada põhilisi aritmeetilisi tehteid: liitmine, lahutamine, korrutamine ja jagamine.

## Nõuded

- Kalkulaator peab olema loodud HTML, CSS ja JavaScript abil
- Kasutaja saab sisestada kaks arvu
- Kasutaja saab valida tehte tüübi (+, -, *, /)
- Tulemus kuvatakse lehel
- Vale sisendi korral (nt tühi väli või mitte-arv) kuvatakse veateade
- Jagamise korral nulliga kuvatakse hoiatus

## Hindamiskriteeriumid

- Kasutajaliides on selge ja loogiline
- JavaScript loogika on eraldatud HTML-ist
- Sisendite valideerimine on olemas
- Vastab kõigile funktsionaalsetele nõuetele
